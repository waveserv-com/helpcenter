# waveserv helpcenter

Official documentation for [waveserv](https://waveserv.com) — setup guides, FAQs, and everything you need to know about our hosting service.

Built with [Mintlify](https://mintlify.com).

## 📖 About

This repository contains the source for our docs site, covering:

- Getting started with waveserv
- Service setup guides
- FAQs & troubleshooting
- Policies and terms

The docs are live at [helpcenter.waveserv.com](https://helpcenter.waveserv.com/) and update automatically whenever changes are pushed to this repo.

## 🐛 Found an issue?

If you spot outdated info, broken links, or errors in the docs, please [open an issue](https://github.com/waveserv-com/helpcenter/issues) or submit a PR — contributions are welcome!
